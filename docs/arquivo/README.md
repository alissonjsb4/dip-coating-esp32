# Arquivo

Documentos de uma tentativa de usar esta máquina como projeto das disciplinas de Internet
das Coisas e TI0179 (2026.2), na aplicação de conservação pós-colheita de fruta com
revestimento comestível.

A equipe optou por outro tema e o projeto voltou a ser o que era: a máquina.

O material fica aqui porque a aplicação continua válida e o levantamento tem valor próprio:
fornecedor de quitosana em Fortaleza, base de dados pública de deterioração de fruta, desenho
do experimento de prateleira, e a análise do que a literatura sustenta e do que não sustenta
sobre velocidade de retirada.

| Arquivo | Conteúdo |
|---|---|
| `proposta.md` | proposta formal do projeto de disciplina |
| `projeto.md` | documento de entrada para equipe |
| `pos-colheita.md` | desenho do experimento de prateleira e formulações |
| `datasets.md` | bases públicas e estrutura da base própria |
| `sensores.md` | sensoriamento da câmara de armazenamento |
